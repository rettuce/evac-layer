# Brand

Wordmark: EVAC LAYER in Public Sans Bold (SIL OFL 1.1, `OFL-PublicSans.txt`), letter-spacing −2 %, no ornament. Glyphs are outlined, so the SVGs need no font.

| File | Use |
|---|---|
| `evac-layer-logo-1line-black.*` | one line, white glyphs, for dark backgrounds |
| `evac-layer-logo-1line-white.*` | one line, black glyphs, for light backgrounds |
| `evac-layer-logo-2line-black.*` | two lines, white glyphs, for dark backgrounds (end card) |
| `evac-layer-logo-2line-white.*` | two lines, black glyphs, for light backgrounds |

PNGs are 2000 px wide with a transparent background. Keep clear space of at least the cap height around the mark.

## App icon and lockup (2026-11-04)

- `evac-layer-icon-black.png` / `evac-layer-icon-white.png` — app icon, 1024×1024: three stacked outline diamonds, a running figure in the top one. Monochrome, stroke 40 px at 1024.
- `evac-layer-lockup-black.png` / `evac-layer-lockup-white.png` — icon + wordmark (Public Sans Bold, +30% tracking), 2380×448. Used at the top of the project README.
- "black" / "white" name the background. Design by Yo Tanaka; wordmark set in Public Sans (OFL, see `OFL-PublicSans.txt`).
