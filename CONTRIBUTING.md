# Contributing

EVAC LAYER is built by You Tanaka during Built with Claude: Japan 2026 (Nov 2–8, 2026).
During the hackathon, external contributions are not accepted (hackathon rule: code by the selected builders only).

After the hackathon, contributions will require a Contributor License Agreement so that the project can keep offering
AGPL-3.0 to the public and a separate commercial license to signage vendors. Issues and questions are welcome anytime.
